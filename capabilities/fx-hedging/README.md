# FX Transaction Hedging — Scenario 5

This capability models a EUR 6,300,000 receivable for a U.S. sawmill-machinery manufacturer invoicing a Finnish lumber mill, with settlement in 182 days.

## Files
- `spec.md` — Stage 2 technical specification (replace with the reviewed `spec-revised.md` draft before the build is considered final)
- `prompt-log.md` — prompt and AI-assistance record
- `model.xlsx` — AI-assisted Stage 3 workbook draft

## Workbook
The workbook compares unhedged conversion, a forward hedge, a three-step money-market hedge, and a EUR put hedge. It includes eleven ending-spot scenarios (-5% through +5% in 1% steps), a chart, the call payoff for a payable variant, and validation checks.
